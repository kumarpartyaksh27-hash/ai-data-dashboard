# 📊 AI Data Analytics & Insights Dashboard

An interactive Data Analytics Dashboard built with Streamlit, Pandas, and Google Gemini API. It allows users to upload CSV datasets, view instant previews, statistics, and generate automated AI-driven business insights and trends.

## ✨ Features
- 📋 CSV Dataset Upload & Instant Preview
- 📈 Automatic Summary Statistics (`pandas.describe()`)
- 🤖 Automated AI Data Analysis & Business Insights via Gemini

## 🚀 Tech Stack
- Python
- Streamlit
- Pandas
- Google Gemini API (`gemini-2.5-flash`)
